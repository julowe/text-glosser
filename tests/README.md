# Tests

## Test Files

This directory contains input and output files to use in tests.
The input and output files share a basename and are differentiated by their
file extension.
Input/Source text is saved as a `.txt` file.
Outputs can include the same formats which this application outputs,
including `.conllu`, `.md`, `.json`, and `.tex`.
Not all output formats are represented in the test files yet.
